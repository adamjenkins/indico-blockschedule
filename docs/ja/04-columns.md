# 4. 列（部屋）

列はグリッドの縦方向の区切りです。実際には部屋であり、その見出しは参加者が印刷物の上端で読む文字になります。

新しいイベントには**列がありません**。列を作るまでグリッドは空のままですが、これは正常な状態で、インストールの失敗ではありません。

## 列を追加する

追加バーの**列**をクリックします。

![列を追加する](../images/ja/07-add-column.png)

入力欄が3つとボタンが1つあります。

- **部屋を選択（任意）…** — サイトの部屋予約の部屋から選べます。選ぶと**名前が自動入力**され、その部屋は参考情報として列に記録されますが、予約が行われるわけではありません。実際に表示されるのは入力した列名です。
  **この欄は、サイトで Indico の部屋予約モジュールが有効な場合にのみ表示されます。** 無効の場合は、列名・色・**列を追加**だけのフォームになりますが、動作はまったく変わりません。
- **列名** — 自由に入力する見出しです。列の見出しとして描かれ、配置された投稿の個別ページに部屋として表示されます。
- 小さな色見本 — 列の色（任意、下記参照）
- **列を追加** — 右端に列を作成します

**列名がすべての基準です。** 部屋を選んだ場合でも、参加者が目にするのは入力した列名です。

**列の名前を変えるには、列見出しのタイトルをクリック**して入力します。

新しい名前はグリッド、表示ページ、印刷物、エクスポートにただちに反映されます。ただし、**すでに配置済みの投稿にはさかのぼって反映されません**。配置した時点で古い列名がその投稿の Indico 個別ページにコピーされており、もう一度動かすまでそのまま残ります。それが問題になる場合は、投稿を入れる*前*に名前を決めるか、あとで一度ドラッグし直してください。

## 色

列には色を設定できます。見出しは濃い色で、列の本体は薄い色合いで描かれます。横に広い用紙の中で、大ホールやポスター会場といった特定の部屋をひと目で見つけられるようにする簡単な方法です。

追加フォームの色見本、または既存の列見出しの色見本から設定します。「色なし」に戻す見本はありません。一度も色を付けていない列はそのまま描かれ、色を付けた後はその色が残ります。

## 並べ替え

**列見出しを別の列見出しにドラッグ**すると、その位置に移動します。順序はただちに保存され、表示ページ、印刷物、表計算のエクスポートすべてでこの順序が使われます。

## 最小幅

各列の見出しには **px** と書かれた小さな入力欄があります。マウスを乗せると**列の最小幅（px、0で指定なし）**と表示されます。

既定では、列は使える幅を等分します。最小幅を指定すると、多くの部屋を同時に表示したときに列が読めないほど狭くなるのを防げます。かわりにグリッドが横スクロールします。

特に読みやすさを保ちたい列がなければ、0 のままでかまいません。

## 列を削除する

列見出しの **✕** で削除します。

- 列が**空**の場合は、確認のうえ削除されます。
- 配置済みの投稿がある場合は、確認画面に**何件が影響を受けるか**が表示されます。それらの投稿は**削除されません**。未配置の投稿パネルに戻り、別の場所に配置できます。

> **複数日のイベントでは、この件数の読み方に注意してください。** 確認画面の件数は**いま表示している日**のものですが、列の削除はイベント全体に及びます。**すべての日**のその列の投稿が未配置の投稿パネルに戻ります。「2件の投稿が…」という表示が、実は40件の一部ということもあり得ます。先に他の日も確認してください。

その列**だけ**にまたがっていた見出し（第7章）は、列とともに削除されます。すべての列がなくなった見出しは、描画される場所がなくなるためです。
