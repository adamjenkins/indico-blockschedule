# 1. はじめに

Block Schedule は、イベントに2つめのタイムテーブルを追加する Indico のプラグインです。**行が時間、列が部屋**という、グリッド形式のタイムテーブルを提供します。カンファレンスのプログラムが紙に印刷されるときの形であり、「どれとどれが重なるか」を議論するときに委員会が頭に思い描く形でもあります。

![管理画面](../images/ja/02-management-page.png)

## 何のための機能か

たくさんの投稿をたくさんの部屋に配置し、1日の全体を一度に見渡す必要があるときに使います。動く部分は3つです。

- **グリッド**そのもの — 1部屋につき1列、1スロットにつき1行
- その横にある**未配置の投稿**パネル — まだ配置されていない投稿がすべて入っています
- 参加者が見る**表示ページ** — 編集用のコントロールを除いた、同じグリッドです

パネルからグリッドへ投稿をドラッグすれば配置され、グリッド上でドラッグすれば移動します。基本操作はこれだけです。

> **プログラムを組む場所は1か所に決めてください。** 未配置の投稿パネルに入るのは、**タイムテーブルの項目をまったく持たない**投稿です。Indico 標準のタイムテーブルですでに時間が割り当てられている投稿は、このパネルにもグリッドにも現れず、自動配置の対象にもなりません。標準のタイムテーブル側で配置を解除するまで、Block Schedule からは見えないままです。どちらのタイムテーブルでプログラムを管理するのか、始める前に決めておいてください。

## Indico 標準のタイムテーブルとの関係

Block Schedule は Indico 標準の**タイムテーブル**を置き換えるものではなく、**並存**します。どちらも使えますし、プログラムの複製が2つできるわけでもありません。ここで投稿を配置すると、Indico 自身のタイムテーブルのデータが実際に書き込まれます。

つまり、次のようになります。

- グリッドに配置した投稿は、標準の**タイムテーブル**にも現れます
- イベントのエクスポート、API、公開タイムテーブルページのすべてが同じ内容を保ちます
- 投稿の個別ページに表示される部屋は、部屋予約のレコードではなく、入力した**列名**です

したがって、プログラムはここで組み立て、Indico の他の部分はこれまでどおり使えます。一方でできないのは、標準タイムテーブルのセッションブロック構造をこのグリッドに表示させることです。Block Schedule は投稿を意図的に最上位の項目として配置し、独自の見出しを描きます（第7章）。

## このマニュアルの対象

このマニュアルは**大会運営者（イベント管理者）**、つまりイベントのプログラムを組み立てて公開する人のために書かれています。Indico のイベント管理画面を開けること、そしてサイトにプラグインがインストール済みであることを前提としています。

サーバー側でのインストールや設定は扱いません。また、参加者向けの案内でもありません。

## 用語について

画面に表示されるとおりの Indico の用語を使います。特に次の語に注意してください。

| 用語 | このマニュアルでの意味 |
|---|---|
| **投稿** | 1件の講演・ポスター・発表。Indico の用語です。パネルの名前も「未配置の投稿」です |
| **トラック** | プログラムのテーマ別の区分。**運営者 → プログラム**で設定します |
| **セッション** | 投稿が属する Indico のセッション |
| **列** | グリッドの縦方向の区切り。実際には部屋ですが、そう決めつけてはいません |
| **全体ブロック** | **すべての**列にまたがって描かれる帯。昼休みや全体講演など |
| **セッションブロック** | **一部の**列にまたがって描かれる見出し。実際のセッションと結び付けることもできます |

第15章に、英語との対照を含む完全な用語集があります。
