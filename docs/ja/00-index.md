# Block Schedule — 大会運営者向けマニュアル

Indico のイベント用の、グリッド形式のタイムテーブルです。行が時間、列が部屋を表します。

このマニュアルは、イベントのプログラムを組み立てて公開する**大会運営者（イベント管理者）**のためのものです。プラグインが Indico サイトにすでにインストールされていること、そしてイベントの管理画面を開けることを前提としています。

## いちばん短い始め方

1. **高度な設定 → 機能** で **Block Schedule** をオンにします。
2. 管理サイドメニューの **Block Schedule** を開きます。
3. **列** → 部屋の名前を入力 → **列を追加**。部屋の数だけ繰り返します。
4. **未配置の投稿**からグリッドへ投稿をドラッグします。
5. **トラックの色**で、各トラックに色を設定します。
6. **閲覧ビューに切替 → Block Schedule** で参加者に見える画面を確認し、よければ**印刷…**します。

このマニュアルの残りは、すべてこの6ステップを詳しくしたものです。
