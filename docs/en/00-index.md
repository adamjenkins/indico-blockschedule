# Block Schedule — Conference Manager's Manual

A grid-based timetable for Indico events: time down the rows, rooms across the
columns.

This manual is for **conference managers** — the people who build and publish an
event's programme. It assumes the plugin is already installed on your Indico
site and that you can reach your event's management area.

## The shortest possible start

1. **Advanced options → Features** — turn **Block Schedule** on.
2. Open **Block Schedule** in the management side menu.
3. **Column** → type a room name → **Add column**. Repeat for each room.
4. Drag talks from **Unscheduled contributions** onto the grid.
5. **Track colours** — give each track a colour.
6. **Switch to display view → Block Schedule** to see what attendees see, and
   **Print…** when you are happy.

Everything else in this manual is refinement of those six steps.
